## Plan (agent output, reviewed by the human before implementation)

While a script runs, the Run button shows a stop square; pressing it stops the run.

- A script runs synchronously in the worker and cannot be interrupted, so
  `stopExecution()` tears the worker down and lets go of its runs (`runScript()` gives them
  undefined). The next run starts a fresh worker and loads the kernel and sheets again.
- The result on screen stays; nothing asked for during the run follows it.
- Every run shows as running now (automatic runs, tool outputs), not only the Run button's;
  Run during a run asks for one more after it instead of being ignored.
- A run on the server goes on.
